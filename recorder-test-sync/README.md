# Light tracker and recorder

New verse-by-verse page for iPad Safari. It is **not published**. The live root and `/test/` are unchanged.

Open `index.html` from this folder (or, once Robin says yes, from `/kjv-recorder/recorder/` on GitHub Pages).

Tracker and recorder sit together. Each verse WAV is saved to Drive **00 Inbox** on Stop, using the live save/upload code. A light word check (whisper-tiny.en q8) flags only missing or added words, or silence. Flagged takes stay on the iPad (IndexedDB) so they can be listened to on the Checks page.

KJV reading text comes from the verified repository at `/home/box/kjv-repository`, with the official Psalm-title and Psalm 119 acrostic cuts only. Wording is otherwise unchanged.
