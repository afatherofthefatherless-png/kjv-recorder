# KJV Recorder (Biblia Dyslexia)

Tracker, verse-by-verse Recorder and Rolling Reader in one page, for A Father of the Fatherless Ministry.
Served by GitHub Pages from the main branch, root folder.

Verse text: generated from the verified KJV repository (`text` field, Psalm titles stripped with reading_text.py).
King James Version (Authorized Version), 1769 text tradition. Digital text from Bible SuperSearch, 'kjv' module v5.6.21, downloaded 2026-11-01; reorganised by the Biblia Dyslexia project. Shared for non-commercial purposes. KJV text public domain in most of the world; UK: Crown copyright under Letters Patent.
